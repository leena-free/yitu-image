# 一图流 · 纯图片版

> 一句话，一张图。本地渲染，不联网、不登录、不需要任何授权。

## 30 秒上手

```bash
# 1. 拿一张空画布（或自己写个 SVG）
#    templates/ 里有三种常用尺寸

# 2. 渲染成 2 倍图
node scripts/render.js -i board.svg -o 我的图.png -s 2
```

就这两步。不需要 API Key，不需要授权，断网也能跑。

## 它和"让 AI 生图"有什么不一样

| | 本技能 | AI 生图模型 |
|---|---|---|
| 文字 | **真文字**，清晰可改 | 必糊，中文尤其 |
| 布局 | 你说了算，像素级可控 | 抽卡，改不动 |
| 一致性 | 同一套配色，批量出图不跑偏 | 每张都不一样 |
| 适合 | 信息图、流程图、架构图、数据图 | 封面、氛围图、插画 |

**要"准确"用这个，要"氛围"用生图模型。**

## 渲染引擎

只有一种：本机 Chrome / Edge 的 headless 截图。**完全离线，不装 npm 包。**

Windows 一般自带 Edge，macOS 一般有 Chrome，脚本会自动找。

常用参数：

```bash
-s 2           # 2 倍图（默认）
-s 3           # 3 倍图，打印用
-o out.png     # 指定输出
```

## 常见问题

**Q：一定要会写 SVG 吗？**
A：不用。让 Agent 写就行，这个技能就是教它怎么写。你自己只看渲染结果。

**Q：能批量出图吗？**
A：能。SVG 是文本，把数据填进模板循环渲染即可。

**Q：能改字吗？**
A：能。改 SVG 里的 `<text>`，重跑渲染，几秒钟。

**Q：要装什么？**
A：只要 Node.js（用来跑 render.js）和本机已有的 Chrome / Edge。没有第三方依赖。
